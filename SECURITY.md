# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The FlashKV team takes security seriously. If you discover a security vulnerability within FlashKV, please do NOT file a public issue on GitHub.

Instead, please send a responsible disclosure email to the maintainers at `security@flashkv.dev` (or open a confidential security advisory on GitHub).

Please include:
- A clear description of the vulnerability.
- Steps or a proof-of-concept to reproduce the behavior.
- The affected component (Server, Core Parser, CLI, or Benchmarking tool).

We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
